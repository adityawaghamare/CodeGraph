# Security Policy

## Supported Versions

Currently, only the latest version of the repository is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to security@codegraph.org. We will respond as quickly as possible, usually within 48 hours.

**Note:** The code analyzed by this tool is strictly parsed for static analysis and is **never** executed. Vulnerabilities related to arbitrary code execution in the analyzed codebases are considered out of scope unless they manage to compromise the analyzer engine itself.
